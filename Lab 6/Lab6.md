# Lab 6 – PWM Project: What We Need to Do

## 1. Initialize the Hardware
- [ ] Initialize the LED output pin
- [ ] Initialize the pushbutton input pin
- [ ] Configure Timer1 for PWM
- [ ] Set the correct PWM frequency

## 2. Read the Pushbutton
- [ ] Check whether the pushbutton is pressed
- [ ] Use the button to change/control the LED behavior

## 3. Control LED Brightness with PWM
- [ ] Use Timer1 PWM output
- [ ] Change the duty cycle to change LED brightness
- [ ] Update the correct OCR register

## 4. Implement the Required LED Behavior
- [ ] Determine the required LED states/modes from the lab
- [ ] Set the appropriate duty cycle for each state
- [ ] Change state when the pushbutton is pressed

## 5. Main Program
- [ ] Call the initialization code once
- [ ] Run an infinite `while(1)` loop
- [ ] Read the pushbutton inside the loop
- [ ] Update the LED/PWM based on the button state

## 6. Test
- [ ] LED turns on correctly
- [ ] Pushbutton is detected correctly
- [ ] LED brightness changes correctly
- [ ] PWM frequency/duty cycle matches the lab requirements
